# RF2: Stop unavailable borrowed runtimes before launch

Spec: [runtime preflight](../specs/02-runtime-preflight.md).
Blocked by: none semantically. Serialize private application after RF1.
Status: approved local slice; unpublished; implementation pending.

## What to build

Check isolated SSL/GitHubKit imports using the exact borrowed virtual environment
before credential/provider launch. Enforce its documented SDK pin and identity;
retain an unavailable-runtime receipt and stop without repair on failure.

## Acceptance criteria

- [ ] Actual stub subprocess controls for healthy identity, import failure and timeout/cleanup.
- [ ] Conflicting environment override, SDK mismatch and metadata drift controls.
- [ ] Failed preflight launches zero credential/provider commands and preserves cooldown/history/catalog.
- [ ] Bound no-sync/no-dependency route and pre/post identity evidence.
- [ ] Read-only existing-runtime control; real failure honestly reported, without repair or retry.
- [ ] Red/green receipts, focused/full checks, independent review and applied/reverified retro findings.
- [ ] Frozen private preimages/postimages and guarded serialized parent application.

No SDK installation, interpreter fallback, schedule change or borrowed repository
write. Preserve unpublished status independently from local verification.
