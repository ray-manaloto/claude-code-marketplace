# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation needed |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified for an agent; dependency gate still applies |
| `ready-for-human` | `ready-for-human` | Human-only action required |
| `wontfix` | `wontfix` | Will not be actioned |

Use these exact labels when skills mention a triage role. A blocking
dependency still gates a ticket even if it carries `ready-for-agent`.
